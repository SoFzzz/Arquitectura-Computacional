Sección 1 y 2 del informe

La aplicación y cómo le generamos carga

Spring PetClinic es la aplicación de ejemplo oficial de Spring Boot: una clínica veterinaria con dueños, mascotas, veterinarios y visitas, sobre una base H2 en memoria. Cada usuario virtual repite este flujo con conexiones persistentes y 50 ms de pausa entre peticiones.

Los entornos comparados

El generador de carga corre en la misma máquina que la aplicación en todos los casos, así la red entre ambos es local y la comparación queda en igualdad de condiciones. Su consumo de CPU se registra aparte para descontarlo.

La pregunta que ordena todo

¿Dónde está esperando la aplicación?

Cada recurso se expresa como porcentaje de lo que el entorno tiene disponible. El que está cerca del 100 % es el cuello de botella; los que están casi en cero no son el problema.

"Si la carga se multiplicara por diez, ¿qué se rompería primero?"

Si la carga se multiplica

Después de la carga sostenida subimos los usuarios concurrentes en escalones de 45 s. Cuando el throughput deja de crecer y la latencia se dispara, el entorno llegó a su límite.
